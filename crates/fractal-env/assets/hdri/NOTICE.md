# Built-in environment maps

`venice_sunset_2k.hdr` - "Venice Sunset" by Greg Zaal, Poly Haven (https://polyhaven.com/a/venice_sunset),
2K equirectangular Radiance HDR. Licensed CC0 1.0 (public domain dedication); no attribution required, credited here.

Embedded through `fractal_env::BUILTINS` and named in scenes as `builtin:venice_sunset_2k`, so a scene with an
environment renders on any machine, in every host of the fractal tracer (WarpBro, ofx-rs).
